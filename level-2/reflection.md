For level 2

I built a responsive restaurant called Umutuzo Kitchen. The website is designed to work well on mobile phones, tablets and desktop screens. I included the main information a custimer may need on the page, such as the restaurant introduction, navigation links, meals, today's special, opening hours, and a short message about visiting the restaurant. I wanted the page to look simple but still fell like an actual restaurant website with information someone could actually want.


For the Grid version, I used CSS Grid to create the 70/30 layout using grid-template-columns: 7fr 3fr. I also used Grid for the menu items and changed the layout to one column on smaller screens. Both versions use the same HTML structure, but the layout is achieved differently.

Between the two, I would personally choose Flexbox because I found the code easier to understand and demonstrate. I also learned that Flexbox is useful when working with one row or one column, while Grid is more useful when working with rows and columns together. However, I understand that both have different strengths and can be useful depending on the layout I am trying to create.

One of the main things I learned from this activity is that every line of CSS can contribute to the final result. A small change in padding, width, flex-basis, or grid columns can affect how the whole page looks. I also learned that leaving too many things at their default values can sometimes cause unexpected results, so it is important to set the properties I need instead of always depending on the browser defaults only.

In general, this activity helped me understand the practical difference between Flexbox and Grid and gave me more confidence in creating responsive layouts.
